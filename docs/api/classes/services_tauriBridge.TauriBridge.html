    Class TauriBridge

    Tauri ネイティブ (Rust) と WebWorker (JavaScript) のハイブリッドIPCブリッジ

    デスクトップ起動時は Rust 製高速 CSV エンジン（memmap2 / rayon / regex）にネイティブ呼び出しを行い、 Webブラウザでのプレビュー実行時は WebWorker に自動フォールバックして同等機能を提供します。
