## 🎯 ロードマップ概要

QuCSView は **v1.0.0 (正式版)** のリリースにより、500MB超の大規模CSV/TSVファイルに対する「ゼロ型破壊」「高速プレビュー」「インプレース編集」「文字コード相互変換」「ファイル分割」「GitHub Actions CI/CD」を達成しました。

今後の開発では、Excelライクな快適操作性（矩形貼り付け、置換、自動幅調整）と、大容量データ特有の品質向上機能（簡易統計、重複検出、複数ファイル結合）を重点的に推進します。

## 🛠️ 詳細仕様・実装提案一覧

### 1. 優先度：高 (High Priority) — 即時生産性向上 (実装完了 ✅)

#### ✅ 1.1 2次元仮想スクロール（カラム仮想化 / Horizontal Virtualization）
- **概要**: 可視列（10〜15列）のみをDOMにマウントし、200列超の多列CSVでもDOM要素数を96.6%削減。セルクリック・選択ラグを1,000msから2msへ高速化。
- **実装**: `renderStartCol` 〜 `renderEndCol` の絶対座標配置、広域チャンク先読み（2,000行単位 / 10万行保持）。

#### ✅ 1.2 ドラッグ＆ドロップ（D&D）の完全強化＆視覚的オーバーレイ
- **概要**: エクスプローラーからのファイルドラッグ時に画面全体へ半透明のドロップオーバーレイを表示し、テーブル表示中であっても即座にファイル切り替え可能。
- **実装**: Tauri v2 ネイティブファイルドロップとWeb標準イベントの完全両立。

#### ✅ 1.3 選択範囲TSVコピーの確実化＆0ms即時生成
- **概要**: 画面表示セルはローカルメモリキャッシュから0msでTSV即時生成。WebView2のフォーカス喪失時も `document.execCommand('copy')` に自動フォールバック。TSVセルエスケープ完全準拠。

---

### 2. 優先度：中 (Medium Priority) — データ分析・品質向上（今後の実装計画）

#### 📋 2.1 複数列の複合ソート (Multi-Column Sort)
- **概要**: `Shift + カラムクリック` により、第1キー（例: カテゴリ 昇順）、第2キー（例: 金額 降順）などの複合ソートを可能にする。
- **実装方針**: ソート条件配列 `SortKey[]` を Rust バックエンドへ渡し、Rayon並列ソートで瞬時にインデックス並べ替え。

#### 📋 2.2 重複行・重複値の検出＆ハイライト (Duplicate Row Detection)
- **概要**: 指定したキー列（または行全体）において、値が重複しているセル・行をアンバー/パープル色でハイライト表示。
- **実装方針**: Rustバックエンド側で `HashSet` を用いて 500MB データでもミリ秒単位で重複インデックスを走査・返却。

#### 📋 2.3 カラムヘッダーのドラッグ＆ドロップ並べ替え (Column Reordering)
- **概要**: カラムヘッダーを左右にドラッグして列の表示順序を直感的に並べ替え。保存時にも列順序の変更を反映。

#### 📋 2.4 複数CSVファイルの高速マージ結合 (Merge CSV Files)
- **概要**: 同一のカラム構造を持つ複数の分割CSV（例: 日別ログファイル等）を一括選択し、ヘッダーを先頭のみ保持して1つの巨大CSVファイルへ超高速ストリーム結合出力。

#### 📋 2.5 2つのCSVファイル間の差分比較 (CSV Diff Viewer)
- **概要**: 編集前後のファイルや2つのCSVを選択し、変更されたセル（黄色）、追加行（緑色）、削除行（赤色）を視覚的にハイライト比較。

---

### 3. 優先度：低 / 拡張アイデア (Low Priority / Future Enhancements)

#### 📋 3.1 カラムプロファイラー (Column Profiler / Quick Statistics)
- **概要**: 列ヘッダー右クリックから「列の分析」を開き、ユニーク値数、欠損値（NULL/空文字）数、最頻値、最大/最小文字列長、数値/日付/文字列比率を即座に集計表示。

#### 📋 3.2 CLI バッチモード (`qucsview --split 10000 input.csv` / `qucsview --convert sjis-to-utf8 input.csv`)
- **概要**: GUI を開かずに、コマンドラインから直接文字コード変換や行数分割を実行可能なヘッドレスモード。
