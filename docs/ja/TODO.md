## 🚀 リリースフェーズ計画

### Phase 1: コアエンジン＆仮想スクロールMVP (完了 ✅)
- [x] Rust `memmap2` によるゼロコピー高速オフセットインデックス構築
- [x] React 19 + TypeScript による仮想スライスレンダリング (30〜50行DOM描画)
- [x] スティッキー固定行番号列およびテーマ切替 (Dark/Light/System)
- [x] F1キーおよび `?` ボタンによるヘルプ＆ショートカットモーダル

### Phase 2: セル直接編集＆ゼロ型破壊保存 (完了 ✅)
- [x] ダブルクリック / Enter / F2 によるインプレースセル編集
- [x] プレーン文字列リテラルの100%保持（先頭0落ち、日付変換の撲滅）
- [x] スパース差分バッファによる安全なストリーミング上書き保存 (`Ctrl + S`)

### Phase 3: 全文検索・ソート・行フィルタ (完了 ✅)
- [x] 全文検索（大文字小文字区別、特定列フィルタ対応）
- [x] 検索一致行の抽出表示（Filter Mode）と元CSV物理行番号の維持
- [x] 単一カラムの昇順/降順ソート機能
- [x] 正規表現（RegEx）対応の高速全文検索（`.*` トグル、構文エラーセーフ、一致ハイライト）

### Phase 4: レガシー文字コード相互変換＆拡張機能 (完了 ✅)
- [x] `Shift_JIS (CP932)`, `UTF-8`, `UTF-8 BOM`, `EUC-JP` / `CRLF`, `LF` 対応
- [x] 選択セル範囲のクリップボードTSVコピー (`Ctrl + C`, `Ctrl + A`, ドラッグ/Shift選択)
- [x] 行番号クリックによる対象行の全体選択＆高視認性ハイライト
- [x] 正規表現（RegEx）対応の高速全文検索（`.*` トグル、構文エラーセーフ、一致ハイライト）
- [x] 表プレビュー ⇔ 生テキスト表示のワンクリック相互切り替え (`RawTextView`)
- [x] 未保存編集セルのアンバー色ハイライト＆右上マーカー表示（保存完了で自動リセット）

### Phase 5: 高度なテーブル操作・データ品質向上 (進行中 🔄)
- [x] 行・列の追加 / 複製 / 削除機能（コンテキストメニュー対応 `TableContextMenu`）
- [x] 編集履歴の Undo / Redo（元に戻す / やり直す `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`）
- [x] 大規模データ対応の高速ファイル分割（Split CSV モーダル `SplitModal`）
- [ ] 複数カラムの複合ソート機能（Shift+クリックによる第1・第2キーソート）
- [ ] 列（カラム）ヘッダーのドラッグ＆ドロップ並べ替え
- [ ] 列幅のダブルクリックによる内容幅への自動フィッティング（Auto-fit）
- [ ] セル範囲の検索＆一括置換（Search & Replace）ダイアログ
- [ ] クリップボードからのTSV / CSV複数セル貼り付け（Paste）対応
- [ ] 重複行の検出・ハイライトおよび簡易集計機能（数値列の合計・平均・件数プレビュー）
- [ ] 大規模データ対応の複数ファイルマージ（Merge）エクスポート
