# ユーザーガイド (User Guide)

[English](../../docs/en/USER_GUIDE.md) | **日本語版**

---

## 1. はじめに

**QuCSView** は、Microsoft Excelで開くと破壊されてしまうコード値（先頭の0や日付形式文字列）を100%安全に保ちながら、数万行〜数百万行（500MB級）・200列超の巨大CSV/TSVを瞬時にプレビュー・直接編集・保存できる超高速デスクトップツールです。

---

## 2. インストール手順

### Windowsインストーラー
1. リリースページより最新の `QuCSView_x64-setup.exe` をダウンロードします。
2. インストーラーを起動し、画面の指示に従ってインストールを完了します。

### ポータブル版 (.zip)
1. `QuCSView_portable.zip` を解凍します。
2. 解凍されたフォルダ内の `QuCSView.exe` を直接ダブルクリックして起動します（レジストリを汚しません）。

## 3. 基本操作フロー

### 3.1 ファイルを開く（ドラッグ＆ドロップ & 履歴）
- **ドラッグ＆ドロップ**: エクスプローラーからCSV/TSVファイルをQuCSViewのウィンドウへ直接ドラッグ＆ドロップします（画面全体にドラッグ中オーバーレイが表示されます）。すでにテーブルを開いている状態からでも別ファイルを直接ドロップして切り替え可能です。
- **ツールバー操作**: 「開く」ボタン（または `Ctrl + O`）をクリックし、ファイルを選択します。
- **最近開いたファイル履歴**: タイトルバーの「履歴」ボタンから、直近開いた最大10件のファイルを1クリックで再読込できます。

### 3.2 セルの閲覧とナビゲーション（2次元仮想スクロール）
- **2次元仮想スクロール**: 縦スクロールだけでなく横スクロールも仮想化（画面に見えている列のみを描画）されているため、200列超の大判CSVでも一切カクつかず滑らかに追従します。
- **キーボード移動**: 矢印キー（`↑`, `↓`, `←`, `→`）でアクティブセルを移動できます。`PageUp` / `PageDown` で1画面ジャンプします。
- **行番号列の固定**: テーブルの横幅が広い場合でも、左端の行番号列（`#`）は常に固定表示されます。
- **列幅自動調整 (Auto-Fit)**: 列ヘッダー右端の境界線を**ダブルクリック**すると、列内の最長テキストに合わせて列幅が瞬時に自動最適化されます。

### 3.3 セルの直接編集 & TSVコピー＆ペースト
1. **セル編集**: 編集したいセルを**ダブルクリック**するか、セル選択状態で **`Enter` または `F2`** キーを押します。値を入力し、**`Enter`**（下へ移動）または **`Tab`**（右へ移動）で確定します。未保存の編集セルはオレンジ色の三角マーカーで強調表示されます。
2. **TSVコピー**: 選択範囲またはセル上で **`Ctrl + C`**（または右クリックメニュー）を押すと、Excel互換のTSV形式でクリップボードへ0msで即時コピーされます。
3. **矩形貼り付け**: クリップボードにコピーされた2次元データを **`Ctrl + V`** でアクティブセルを起点に矩形状に一括反映できます（Undo対応）。
4. **元に戻す / やり直し (Undo / Redo)**: **`Ctrl + Z`** で直前の編集や貼り付け、置換、行/列操作を取り消し、**`Ctrl + Y`**（または `Ctrl + Shift + Z`）でやり直せます。
5. **行・列の追加 / 複製 / 削除**: セルや行番号、ヘッダー上で**右クリック**するとコンテキストメニューが表示され、行や列の挿入・複製・削除が行えます。

### 3.4 全文高速検索 & 一括置換 (Ctrl+H) & 行絞り込み (Filter Mode)
1. **`Ctrl + F`** を押して検索バーに文字を入力します。
2. **`.*` ボタン** を押すことで正規表現検索モードに切り替わります（例: `\d{3}-\d{4}` で郵便番号抽出）。
3. **`Enter`** で次のマッチ、**`Shift + Enter`** で前のマッチへジャンプします。
4. **検索と置換 (`Ctrl + H`)**: ツールバーの「置換」ボタンまたは `Ctrl + H` で置換ダイアログを開き、正規表現キャプチャグループ（`$1` 等）を用いた単一・一括置換を実行できます。
5. 検索バー右側の **「絞込 (Filter)」** ボタンを押すと、一致した行のみを抽出表示できます。

### 3.5 表プレビュー ⇔ 生テキスト表示切替 & 高速ファイル分割
- **表示モード切替**: ツールバーの **「表 / テキスト」** ボタンで、グリッドプレビューと生テキストエディタを瞬時に切り替えられます。
- **高速ファイル分割**: ツールバーの **「分割」** ボタンから、指定行数（1,000行、10,000行単位など）ごとにCSVを分割して一括・個別保存できます。

### 3.6 文字コード・改行コードの変換と保存
- ツールバーの **「保存」** ボタン（または **`Ctrl + S`**）を押すと、現在の文字コード（`UTF-8`, `Shift_JIS`, `EUC-JP`）や改行コード（`CRLF`, `LF`）を維持したまま高速保存されます。
- **`Ctrl + Shift + S`** で別名保存やエンコーディング変換保存が可能です。

## 4. 主なユースケース

1. **基幹システム・ECモールの商品CSV確認・編集**:
   - `00123` のような商品コードや `090-XXXX-XXXX` のような電話番号をExcelに壊されることなく安全に編集。
2. **Shift_JIS (CP932) 形式レガシーCSVのメンテナンス**:
   - 文字化けを起こさずにShift_JIS形式のまま安全に閲覧・編集・保存。
3. **数百万行の大規模アクセスログ・センサーデータの高速確認**:
   - 巨大ログを数秒待たされることなく瞬時に開いて全文検索。

## 5. よくある質問 (FAQ)

- **Q: Excelのようにセル内の計算式（SUM関数など）は使えますか？**
  - **A:** QuCSVPreviewは「データ型破壊を防ぐプレーンテキストビューアー＆エディタ」として設計されているため、数式の自動計算機能は意図的に搭載していません。
- **Q: 500MBのファイルを開いた時、PCのメモリを圧迫しませんか？**
  - **A:** Rustのメモリマップ機能により、500MBファイル展開時でもメモリ消費量は40MB前後です。低スペックPCでも快適に動作します。
