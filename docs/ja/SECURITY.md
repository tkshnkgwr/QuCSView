# セキュリティポリシー (Security Policy)

[English](../../docs/en/SECURITY.md) | **日本語版**

---

## 1. セキュリティ設計とファイルアクセス権限

QuCSVPreviewは、ユーザーが明示的に開いたローカルファイルのみを操作するセキュアなデスクトップアプリケーションです。

1. **サンドボックスとIPCスコープ**:
   - Tauri v2の機能権限設定（Capabilities）により、任意のシステムコマンド実行や権限外ファイルシステムアクセスを制限しています。
2. **外部通信の非接続性 (Offline-First)**:
   - CSV/TSVファイルのパース、編集、検索、エンコード変換はすべてローカル環境内で完結し、外部ネットワークへのデータ送信は一切行いません。

---

## 2. 脆弱性の報告窓口

セキュリティ上の脆弱性やデータ破損に関する重大な問題を発見された場合は、公開Issueを作成せず、以下の窓口までご連絡ください。

- **連絡先メールアドレス**: `security@qucsvpreview.example.com`
- **報告時の記載事項**:
  - 対象バージョン (例: v0.1.0)
  - 脆弱性の詳細と再現手順 (PoC)
  - 影響範囲

報告受領後、48時間以内に初期確認と対応予定をご連絡いたします。
