## 2. コア設計思想とゼロ型破壊ポリシー

### 2.1 Microsoft Excelの型破壊問題と完全撲滅仕様
Microsoft ExcelでCSVを開いた際に発生する以下のデータ変質事故を、QuCSViewでは**100%遮断**します。

1. **先頭ゼロ落ちの防止**:
   - `0123` や `00987654` などのコード値・郵便番号・電話番号を数値として扱わず、**厳密に文字列リテラルとして保持・編集・出力**します。
2. **勝手な日付型変換の防止**:
   - `1-2` や `2026/08` などの形式がExcelによって日付オブジェクトへ変質する問題を排除します。
3. **指数表記化の防止**:
   - `1234567890123456` などの長い数値文字列が `1.23457E+15` のように桁落ちする問題を排除します。

## 3. ファイル形式 & エンコーディング仕様

### 3.1 対応ファイル形式
- **CSV (Comma-Separated Values)**: `,` 区切り
- **TSV (Tab-Separated Values)**: `\t` 区切り
- **カスタム区切り文字**: セミコロン (`;`)、パイプ (`|`)

### 3.2 対応文字コード & 改行コード
- **エンコーディング**: `UTF-8`, `UTF-8 (BOM付)`, `Shift_JIS (CP932 / Windows-31J)`, `EUC-JP`
- **改行コード**: `CRLF` (Windows標準), `LF` (Unix/Linux標準)
- **文字コード自動判定**: ファイル読み込み時にバイトヘッダーおよびエンコーディングパターンを自動判別。保存ダイアログまたは再読み込みで自在に変換可能。

### 4.1 選択セル範囲のクリップボードTSVコピー (`Ctrl + C`)
- **自由な範囲選択**:
  - `Shift + クリック`、`Shift + 矢印キー`、またはマウスドラッグによる複数セル・複数行・複数列の矩形選択。
  - `Ctrl + A` によるテーブル全セル範囲選択。
  - 左端の行番号クリックによる1行全体の全幅選択。
- **TSVコピー機能**:
  - `Ctrl + C` 押下時、選択範囲内のセルデータをタブ区切り（`\t`）および改行（`\n`）のTSV形式文字列として構築し、クリップボードへ保存。
  - ソート状態およびフィルタ状態の行順序を完全反映。
  - コピー完了時に画面右下にコピー行数・列数・セル数を表示するフローティングトースト（`#toast-clipboard-copy`）を通知。

### 4.2 正規表現（RegEx）対応の高速全文検索
- **正規表現モード切替 (`.*` トグルボタン)**:
  - ツールバーの `.*` ボタンをクリックすることで正規表現検索モードをON/OFF。
  - 例: `\d{3}-\d{4}` (郵便番号), `0[789]0\d{8}` (携帯番号), `^[A-Z]{3}` などの高度なパターン一致検索に対応。
- **堅牢なエラーハンドリング**:
  - 未完結のブラケット等による構文エラー時は赤色アウトラインとツールチップで通知し、アプリのクラッシュを防止。
- **正規表現マッチのカラーハイライト**:
  - セル内の正規表現一致部分を `<mark>` 要素で即座にハイライト描画。

### 4.3 スティッキー行番号列・行選択ハイライト仕様
- **完全固定のスティッキー行番号**: 水平スクロール時に左端の行番号列（`#`）は `position: sticky; left: 0;` により完全固定。
- **行番号クリックによる対象行の全体選択**:
  - 行番号セル（`#row-num-{virtualRowIdx}`）をクリックすることで、該当行全体が即座に選択状態となり、先頭列（col: 0）にフォーカスが当たります。
  - 行番号セルにはホバーフィードバック（青色背景・文字ハイライト）と、クリックで行選択できる旨のツールチップ（`title`）を付与。
- **選択行（Selected Row）の高コントラスト・ハイライト強調**:
  - **行番号セル**: 選択された行の行番号セルは鮮やかなブルー背景（`bg-blue-600`）＋白文字（`text-white font-bold`）＋境界シャドウで強調表示。
  - **行全体**: 選択行全体の背景をアクセントハイライト（ダーク: `bg-blue-950/40 border-[#2563EB]/50`、ライト: `light:bg-blue-100/70 light:border-blue-300`）で強調。

### 4.4 行・列のコンテキストメニュー操作 (右クリック)
- テーブルヘッダー、行番号、セル上で右クリックした際、直感的なコンテキストメニュー (`TableContextMenu`) を表示。
- **行操作**: 上に行を挿入、下に行を挿入、行を複製、行を削除。
- **列操作**: 左に列を挿入、右に列を挿入、列を複製、列を削除。

### 4.5 編集履歴 Undo / Redo
- **取り消し (`Ctrl + Z`) / やり直し (`Ctrl + Y` または `Ctrl + Shift + Z`)**:
  - セルのテキスト編集だけでなく、行や列の挿入・複製・削除によるデータ構造変更もスタックで管理し、完全に双方向で復元・再適用可能。
  - ツールバーの専用 Undo / Redo アイコンボタンからも実行可能。

### 4.6 大規模データ高速ファイル分割 (Split CSV)
- ツールバーの「分割」ボタンからファイル分割ダイアログ (`SplitModal`) を展開。
- 行数（例: 1,000行、10,000行単位）を指定し、1行目のヘッダーを各分割ファイルに自動保持させた状態で、個別ファイルダウンロードおよび一括ダウンロードに対応。

### 4.7 表プレビュー ⇔ 生テキスト表示の即時切替
- ツールバーの切替スイッチにより、仮想テーブルプレビュー（`VirtualTable`）と生テキストエディタ（`RawTextView`）をミリ秒単位で同期切り替え。

## 5. キーボードショートカット一覧

| ショートカット | 対象・契機 | 動作仕様 |
| :--- | :--- | :--- |
| **`Ctrl + Z`** | テーブル操作 | 直前の操作を元に戻す (Undo: セル編集・行/列挿入・削除) |
| **`Ctrl + Y` / `Ctrl + Shift + Z`** | テーブル操作 | 直前に取り消した操作をやり直す (Redo) |
| **`右クリック`** | セル/行番号/ヘッダー | 行・列の挿入 / 複製 / 削除コンテキストメニューを表示 |
| **`Ctrl + O`** | グローバル | ファイル選択ダイアログを開く |
| **`Ctrl + S`** | グローバル | ファイル上書き保存（未保存時は保存設定ダイアログ） |
| **`Ctrl + Shift + S`** | グローバル | 名前を付けて保存ダイアログを開く |
| **`Ctrl + C`** | テーブル操作 | 選択セル範囲 / 選択行をTSV形式でクリップボードにコピー |
| **`Ctrl + A`** | テーブル操作 | テーブル内の全セルを選択 |
| **`Shift + 矢印 / クリック`** | テーブル操作 | セル範囲の拡張選択（複数行・複数列） |
| **`Ctrl + F`** | グローバル | 全文検索インプットへフォーカス移動 |
| **`F1`** | グローバル | ヘルプ＆ショートカット仕様モーダルを開閉 |
| **`Enter` / `F2`** | セル選択時 | 選択セルの直接インプレース編集を開始 |
| **`Enter`** | セル編集中 | 編集を確定し、1行下のセルへ移動 |
| **`Tab`** | セル編集中 | 編集を確定し、1列右のセルへ移動 (`Shift+Tab` で左へ移動) |
| **`Esc`** | セル編集中 | 編集内容を破棄し、元の値へロールバック |
| **`矢印キー`** | セル選択時 | アクティブセルを上下左右へ移動（画面外は自動スクロール） |
| **`PageUp / PageDown`** | セル選択時 | ビューポート1画面分の高速スクロール移動 |
