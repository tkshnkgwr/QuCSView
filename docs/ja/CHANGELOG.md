## [0.3.0] - 2026-08-26

### 追加 (Added)
- **行・列の構造編集機能（右クリックコンテキストメニュー） (`TableContextMenu.tsx`, `VirtualTable.tsx`, `csvWorker.ts`, `tauriBridge.ts`, `App.tsx`)**:
  - セル、行番号列、ヘッダー上で右クリックした際に専用のコンテキストメニューを開き、上/下への行挿入、行複製、行削除、左/右への列挿入、列複製、列削除を即座に実行可能。
- **編集履歴 Undo / Redo 機能 (`App.tsx`, `VirtualTable.tsx`, `Toolbar.tsx`, `types/csv.ts`, `HelpModal.tsx`)**:
  - `Ctrl + Z`（元に戻す）および `Ctrl + Y` / `Ctrl + Shift + Z`（やり直す）、ツールバーの専用ボタンから、セル値編集と行・列構造変更の完全な巻き戻し・再適用が可能。
- **大規模CSV高速ファイル分割機能 (`SplitModal.tsx`, `Toolbar.tsx`, `csvWorker.ts`, `tauriBridge.ts`, `App.tsx`)**:
  - 指定行数（1,000行、10,000行等）での高速分割エクスポートモーダルを追加。ヘッダーの自動維持、個別/一括ダウンロードをサポート。
- **表プレビュー ⇔ 生テキスト表示の即時切替機能 (`Toolbar.tsx`, `RawTextView.tsx`, `App.tsx`)**:
  - ツールバー上のトグルボタンで、テーブル表示とプレーンテキストエディタ表示をミリ秒単位で同期切り替え。
- **未保存編集セルの視覚的強調表示 (`VirtualTable.tsx`, `Toolbar.tsx`)**:
  - 編集中のセルをアンバー色背景・アクセント枠線・右上マーカーで強調表示し、ツールバーの保存ボタンおよびステータスバーに変更件数を表示。保存完了時に自動リセット。

## [0.2.0] - 2026-08-21

### 追加 (Added)
- **選択セル範囲のクリップボードTSVコピー (`Ctrl + C`) (`VirtualTable.tsx`, `csvWorker.ts`, `tauriBridge.ts`)**:
  - Shift+ドラッグ、Shift+クリック、Shift+矢印キー、および `Ctrl + A` による自由なセル範囲選択をサポート。
  - `Ctrl + C` 押下時に、選択範囲のセルデータをタブ区切り（TSV）形式でクリップボードへ高速出力。ExcelやGoogleスプレッドシート、各種テキストエディタにそのまま格子状データとしてペースト可能。
  - コピー完了時に画面右下にコピーされた行数・列数・セル数を表示するフローティングトースト（`#toast-clipboard-copy`）を表示。
- **正規表現（RegEx）対応の高速全文検索 (`Toolbar.tsx`, `VirtualTable.tsx`, `csvWorker.ts`, `tauriBridge.ts`, `App.tsx`)**:
  - ツールバーに `.*` 正規表現トグルボタンを追加。
  - 正規表現構文エラー（閉じ忘れ等）を安全に捕捉する例外処理・エラーメッセージ通知を実装し、アプリのクラッシュを完全に防止。
  - セル内の一致部分を正規表現パターンに基づき `<mark>` 要素でリアルタイムにハイライト描画。
- **行番号（行数）クリックによる対象行の全体選択機能 (`VirtualTable.tsx`)**:
  - 左側の固定行番号セルをクリックすることで、該当行全体が即座にアクティブ・選択行として認識されるインタラクションを実装。
  - 選択行の行番号セルを鮮やかなブルー背景（`bg-blue-600`）＋白文字（`text-white font-bold`）＋境界シャドウで目立たせ、現在フォーカスされている行を一目で直感的に把握可能。
- **ヘルプモーダルの概要・特徴・使い方ガイド・FAQタブ大幅拡充 (`HelpModal.tsx`)**:
  - アプリ概要と開発コンセプト（Excel型破壊防止、500MB高速仮想描画、Rustメモリマップドインデックス、低スペックPC最適化）。
  - 主要な特徴（型破壊完全排除、仮想スライス描画、直接セル編集＆行選択、TSVクリップボードコピー、正規表現全文検索、文字コード・改行コード対応、ヘッダーなしCSV対応）。
  - 全17キーボードショートカット一覧テーブル。

## [0.1.2] - 2026-08-20

### 追加 (Added)
- **「一行目をヘッダとする」切替機能 (`Toolbar.tsx`, `VirtualTable.tsx`, `csvWorker.ts`, `csv_engine.rs`)**:
  - ツールバーに「一行目をヘッダとする」チェックボックス（`#checkbox-has-header`）を追加。
  - チェックON時: 1行目をカラム名（ヘッダー）としてパースし、2行目以降をデータ行として表示。
  - チェックOFF時（ヘッダーなしCSV）: ヘッダー行に明確に `NULL` を表示し、CSVの1行目からすべての行を実データ行として表示・編集・エクスポート可能。

### 変更・改善 (Changed / Improved)
- **検索一致件数バッジの枠外配置 (`Toolbar.tsx`)**:
  - 検索文字入力時に検索入力枠のサイズが伸縮・横揺れする現象を防止するため、検索一致件数（`#search-match-badge`：件数表示および▲▼前後移動ボタン）を検索入力枠の外側・左側に独立配置。
  - 全文検索フィールド（`w-48 shrink-0`）は常に固定サイズを保ち、テキスト入力・クリア時にもブレない安定した操作性を実現。
- **「Excel型破壊防止」バッジの削除 (`Toolbar.tsx`)**:
  - 画面の省スペース化とユーザー要望に基づき、ツールバーの不要なバッジを完全撤去。

## [0.1.0] - 2026-08-20
