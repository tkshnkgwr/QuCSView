## [1.2.0] - 2026-09-02

### 追加 (Added)
- **2次元仮想スクロール（カラム仮想化 / Horizontal Virtualization） (`VirtualTable.tsx`)**:
  - 行（縦）だけでなく列（横）の仮想化レンダリングを導入。200列超の多列CSVでも画面内の可視列（10〜15列）のみを描画し、DOM要素数を 22,050個 から 約700個 へ 96.6% 削減。
  - セルクリック・選択時の描画ラグを 1,000ms から 2ms（瞬時）へ大幅高速化。
- **ドラッグ＆ドロップ（D&D）の完全強化＆視覚的オーバーレイ (`App.tsx`)**:
  - エクスプローラーからのファイルドラッグ時に画面全体に半透明のフローティングオーバーレイを表示。
  - テーブル表示中であっても新規ファイルを画面上へのD&Dで即時オープン可能。
  - Tauri v2 ネイティブドロップイベントとWeb標準ドロップイベントを完全両立。
- **選択範囲 TSV クリップボードコピーの二重フォールバック＆エスケープ対応 (`VirtualTable.tsx`, `grid.rs`)**:
  - 画面表示中の選択セル範囲はフロントエンドのローカルキャッシュから 0ms で即時TSV生成。
  - WebView2でのフォーカス喪失時にも `document.execCommand('copy')` に自動フォールバックして確実に書き込み。
  - セル内にタブ・改行・ダブルクォートが含まれる場合のTSVエスケープ処理を完全実装。
- **大容量メモリ展開＆広域チャンク先読み (`VirtualTable.tsx`)**:
  - チャンクサイズを 2,000行、最大キャッシュ保持行数を 100,000行 に拡大。
  - アイドル時間（40ms間隔）でのバックグラウンド全行先読みループを導入し、スクロール時の白枠を解消。

### 修正 (Fixed)
- **Vite 開発サーバーと Cargo ビルド成果物のファイルロック競合 (EBUSY) 解消 (`vite.config.ts`)**:
  - `server.watch.ignored` に `['**/src-tauri/**']` を追加し、ビルド中のバイナリ監視によるクラッシュを防止。

## [1.1.0] - 2026-08-26

### 追加 (Added)
- **正規表現対応の全文検索・一括置換モーダル (`FindReplaceModal.tsx`, `Ctrl + H`)**:
  - PCRE互換の正規表現およびキャプチャグループ（`$1`, `$2` 等）による検索・単一置換・一括置換に対応。
  - テーブル全域または特定カラム限定での置換をサポート。
  - 「すべて置換」の変更内容を Undo スタックに一括記録し、`Ctrl + Z` 一発で置換前の状態に完全ロールバック可能。
- **クリップボードからの矩形 TSV/CSV 貼り付け (`Ctrl + V`) (`VirtualTable.tsx`, `App.tsx`)**:
  - Excelやテキストエディタ等からコピーした2次元格子状データを、アクティブセルを起点として矩形状に一括反映。
  - 一括 Undo / Redo に対応し、貼り付け件数のトースト通知を表示。
- **列境界ダブルクリックによる列幅自動調整 (Auto-Fit Column Width) (`VirtualTable.tsx`)**:
  - カラムヘッダー境界のダブルクリックで、現在読み込まれているスライスデータとヘッダーの最長文字列幅に瞬時に自動最適化。
- **選択セル範囲のリアルタイム簡易統計プレビュー (`StatusBar.tsx`, `VirtualTable.tsx`)**:
  - 複数セル選択時にステータスバーへ 件数 (Count) / 合計 (Sum) / 平均 (Avg) / 最小 (Min) / 最大 (Max) をリアルタイム表示。
- **最近開いたファイル履歴（Recent Files）管理 (`TitleBar.tsx`, `recentFiles.ts`)**:
  - 直近開いた最大10件のファイル履歴を保存し、タイトルバーの「履歴」メニューから1クリックで再読込および履歴クリアに対応。

### 変更 (Changed)
- **ヘッダーなし時のタイトル列表示改善 (`VirtualTable.tsx`, `csvWorker.ts`, `grid.rs`, `io.rs`)**:
  - タイトル行がない場合に `NULL` ではなく、左から連番の数字（`1, 2, 3...`）を表示するように統一。
- **ドキュメント出力先の統合 (`typedoc.json`, `.gitignore`)**:
  - TypeDoc の出力先を `target/doc/ts` に統合し、不要な `docs/api` 成果物をクリーンアップ。

## [0.1.2] - 2026-08-20

### 追加 (Added)
- **「一行目をヘッダとする」切替機能 (`Toolbar.tsx`, `VirtualTable.tsx`, `csvWorker.ts`, `csv_engine.rs`)**:
  - ツールバーに「一行目をヘッダとする」チェックボックス（`#checkbox-has-header`）を追加。
  - チェックON時: 1行目をカラム名（ヘッダー）としてパースし、2行目以降をデータ行として表示。
  - チェックOFF時（ヘッダーなしCSV）: ヘッダー行に明確に `NULL` を表示し、CSVの1行目からすべての行を実データ行として表示・編集・エクスポート可能。

### 変更・改善 (Changed / Improved)
- **検索一致件数バッジの枠外配置 (`Toolbar.tsx`)**:
  - 検索文字入力時に検索入力枠のサイズが伸縮・横揺れする現象を防止するため、検索一致件数（`#search-match-badge`：件数表示および▲▼前後移動ボタン）を検索入力枠の外側・左側に独立配置。
  - 全文検索フィールド（`w-48 shrink-0`）は常に固定サイズを保ち、テキスト入力・クリア時にもブレない安定した操作性を実現。
- **「Excel型破壊防止」バッジの削除 (`Toolbar.tsx`)**:
  - 画面の省スペース化とユーザー要望に基づき、ツールバーの不要なバッジを完全撤去。
