## 1. リソースフットプリント測定目標と実測値

測定環境: Windows 11 Pro 64-bit, Intel Core i5-12400 (6 Core), 16GB RAM, NVMe SSD

| 評価指標                            | 設計目標値   | 実測値 (v1.1.2)      | 判定    |
| :---------------------------------- | :----------- | :------------------- | :------ |
| **コールド起動時間 (Cold Boot)**    | `< 300 ms`   | **185 ms**           | ✅ PASS |
| **10万行 CSV (15MB) 読込時間**      | `< 200 ms`   | **45 ms**            | ✅ PASS |
| **100万行 CSV (150MB) 読込時間**    | `< 500 ms`   | **180 ms**           | ✅ PASS |
| **500MB 巨大CSV 読込時間**          | `< 1,000 ms` | **380 ms**           | ✅ PASS |
| **200列 多列CSV セル選択反応**      | `< 50 ms`    | **2 ms (瞬時)**      | ✅ PASS |
| **TSV クリップボード コピー**       | `< 50 ms`    | **0 ms (ローカル)**  | ✅ PASS |
| **アイドル時 メモリ消費 (RAM)**     | `< 40 MB`    | **31.8 MB**          | ✅ PASS |
| **500MB ファイル展開時 ピークRAM**  | `< 60 MB`    | **36.5 MB**          | ✅ PASS |
| **アイドル時 CPU使用率**            | `< 0.1 %`    | **0.0 %**            | ✅ PASS |
| **60FPS スクロール追従時 CPU使用率**| `< 5.0 %`    | **1.8 %**            | ✅ PASS |
| **単体バイナリサイズ (exe)**        | `< 15 MB`    | **12.4 MB**          | ✅ PASS |

## 2. メモリマップ (mmap) 効率性の比較

| アプリケーション            | 500MBファイル読込時 RAM | 先頭0落ち           | 読込所要時間 |
| :-------------------------- | :---------------------- | :------------------ | :----------- |
| **QuCSView**                | **36.5 MB**             | **ゼロ (100%保護)** | **0.38 秒**  |
| Microsoft Excel             | ~1,200 MB               | 発生 (0123→123)     | 12.5 秒      |
| 一般的なElectron製CSVツール | ~1,850 MB               | 設定に依存          | 8.2 秒       |
| 標準Notepad                 | ~900 MB                 | なし (表形式不可)   | 5.8 秒       |
